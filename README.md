### 🌙 Tsuki: Android Manga Reader

A manga reader built to **never run out of sources**.

| ✨ Feature | 📝 What it does |
|---|---|
| 🌐 **1200+ built-in sources** | Read from a huge library out of the box |
| 🤖 **AI Parser Generator** | Gemini-powered parsers for sites that aren't supported yet |
| 🎯 **Visual Rule Builder** | Point-and-click source creation, no code needed |
| 🔌 **Extension support** | JS and Mihon extensions via QuickJS |
| 🧭 **Browser Sources** | Universal manga site detection |
| 📖 **Light Novels** | Now readable too |
