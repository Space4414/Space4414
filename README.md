## Spotlight: [Tsuki](https://github.com/TsukiAndroid/Tsuki)

An Android manga and light novel reader built so your library doesn't break every time a single source changes.

<div align="center">

<a href="https://github.com/TsukiAndroid/Tsuki/stargazers"><img src="https://img.shields.io/github/stars/TsukiAndroid/Tsuki?style=for-the-badge&logo=github&color=ec4899&labelColor=18181b&label=STARS" /></a>
<a href="https://github.com/TsukiAndroid/Tsuki/fork"><img src="https://img.shields.io/github/forks/TsukiAndroid/Tsuki?style=for-the-badge&logo=github&color=a855f7&labelColor=18181b&label=FORKS" /></a>
<a href="https://github.com/TsukiAndroid/Tsuki/commits"><img src="https://img.shields.io/github/last-commit/TsukiAndroid/Tsuki?style=for-the-badge&color=6366f1&labelColor=18181b&label=UPDATED" /></a>

</div>

<br/>

> **Core idea:** Keep reading smooth across changing sites with built-in sources, flexible rule builders, and AI-assisted parser creation.

* **1,200+ Built-in Sources** — Ready-to-explore catalog right out of the box
* **AI Parser Generator** — Gemini-powered parser generation for sites that need custom handling
* **Visual Rule Builder** — Build sources visually without writing everything by hand
* **Extension Support** — QuickJS-backed JS and extension ecosystem compatibility
* **Browser & Light Novels** — In-app site detection alongside novel reading support
